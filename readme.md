# Simple Monobank Gateway for WooCommerce

Lightweight Monobank payment gateway for WooCommerce with automatic order updates and payment tracking.

---

## Features

✅ Monobank payment gateway  
✅ Automatic order status updates  
✅ Payment history panel with Manual payment status check  
✅ Multilingual support  
✅ Ukrainian localization included  

Designed to be lightweight and easy to configure.

---

## Installation

1. Upload plugin to:

```text
/wp-content/plugins/
```

2. Activate plugin

3. Open:

```text
WooCommerce → Settings → Payments
```

4. Enable:

```text
Simple Monobank Gateway
```

5. Enter your Monobank API token

6. Save settings
