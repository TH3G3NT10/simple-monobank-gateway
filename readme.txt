Lightweight Monobank payment gateway for WooCommerce with automatic order updates and payment status tracking.

== Description ==

Simple Monobank Gateway adds Monobank acquiring support for WooCommerce.

Features:

* Monobank payment gateway
* Automatic order status updates
* Manual payment status check
* Webhook support
* Payment history panel
* Multilingual support
* Ukrainian localization included

Designed to be lightweight and easy to configure.

== Installation ==

1. Upload the plugin to `/wp-content/plugins/`
2. Activate the plugin
3. Go to WooCommerce → Settings → Payments
4. Enable "Simple Monobank Gateway"
5. Enter your Monobank API token
6. Save settings

== Frequently Asked Questions ==

= Does this plugin require WooCommerce? =

Yes. WooCommerce must be installed and activated.

= Does this plugin support Ukrainian language? =

Yes. Ukrainian localization is included.

= Does it support Google Pay and Apple Pay? =

If available through Monobank acquiring, yes.
